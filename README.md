# MEGALAB · Registro prospectivo de ForecastBench

Esta rama conserva archivos de pronósticos propios emitidos por el laboratorio antes del cierre de cada ronda, comprobantes de tiempo de GitHub y las resoluciones públicas elegibles. El programa trabaja en sombra sin credenciales de entrega. El comprobante de la organización responsable es necesario para acreditar una participación oficial.

Los datos y las previsiones de otros equipos destinados a pruebas históricas se encuentran en la rama de [investigación](https://github.com/xmjunior/mmegalab-futureeval-bot/tree/research/omega-infinity/research/omega). Las métricas del laboratorio distinguen referencias, modelos y familias de preguntas compartidas. Las rondas vencidas conservan cualquier ausencia de emisión.
