# Blind and anchored forecasts of the US Treasury curve

Five Tuesday issue windows in UTC, from 24 November through 22 December 2026. A missed window stays missing. Each case asks whether the official 10Y minus 2Y par-yield spread on the first complete Treasury observation on or after the following Tuesday is strictly higher than its last available value before the issue day. The resolution uses the existing Treasury seven-day search window and two-day publication lag. Stable case identity is the issue date. A dated data snapshot fixes the reference before any model call.

One free Groq call per arm and per issue. Both see the same resolution rule, historical count and five latest daily spread changes. One sees the numerical Beta(2,2) anchor, the other sees only the inputs. Calls are separate and unthreaded, with no tools. Alternating order by week limits order effects. Additional fixed baselines are the anchor and 0.5. The common five-trading-observation analogue is a proxy when an evaluation interval contains a holiday. These spread changes share one underlying series and the two LLM estimates share one model. The pilot tests anchoring and operational continuity; five correlated events cannot qualify a strategy for production.

Compare Brier and natural log loss on common resolved events; disclose missing outputs and unanswered events. Do not replace a missing estimate with 0.5. Report the paired scores, calibration-in-the-large and raw counts. Freeze inputs, prompt hashes, one-time leases and responses before outcomes. All actions are independent of tournaments; no Metaculus credential, OpenAI API key, spending or automatic production changes. Never backfill a forecast issued too late.
