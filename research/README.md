## Operación y recuperación

1. Conserva acceso al repositorio GitHub y a la cuenta humana de Metaculus que administra el bot. El [panel de Actions](https://github.com/xmjunior/mmegalab-futureeval-bot/actions) muestra el evento, el SHA del workflow y sus trabajos. Una prueba por push o despacho acredita esa vía; consulta por separado la columna `event=schedule` para verificar el reloj. GitHub evalúa el cron de la rama predeterminada. En forks públicos la programación puede quedar desactivada tras 60 días sin actividad.
2. Los motores de temporada, MiniBench y Market Pulse se ejecutan en runners Linux estándar de GitHub. El control de investigación de main ejecuta un SHA exacto de esta rama. Un control horario comprueba si el despachador original estuvo activo en los últimos 42 minutos. Solo lo reactiva en main si verifica una pregunta abierta y sin pronóstico propio. Las ventanas recientes no gastan llamadas a modelos. El trabajo de cálculo no escribe en GitHub; otro trabajo sin claves de modelos guarda los JSON en [research/champion-observations/records](https://github.com/xmjunior/mmegalab-futureeval-bot/tree/research/champion-observations/records). Cada registro lleva un evento, ID de ejecución, revisión de código y resultados de pasos. Ahí se guardan el índice de rondas MiniBench, los pronósticos propios de Treasury y las auditorías de aceptación.
3. Para restaurar en el mismo repositorio, recupera main y las ramas `research/champion-v2`, `research/champion-observations` y `market-pulse/26q4`. Mantén las revisiones fijadas en los YAML. Para recuperar en otro repositorio, transfiere también el historial de esas ramas, revisa las referencias al propietario/nombre, conserva el mismo usuario bot, y habilita los workflows en Actions. Las fechas de Git de los primeros registros son necesarias para atribuir resultados prospectivos.
4. En Settings → Secrets and variables → Actions, el token del bot es `METACULUS_TOKEN`. Las claves de los modelos son `GEMINI_API_KEY` y `OPENROUTER_API_KEY`. Los valores se recuperan desde las cuentas originales o se regeneran con los proveedores si procede. Los secretos existentes continúan con el repositorio aunque cambie ChatGPT o el ordenador. AskNews necesita su acreditación independiente. El laboratorio nunca habilita rutas pagadas con una clave personal. El token temporal de cada trabajo lo emite GitHub.
5. Para reproducir localmente el trabajo productivo, instala Python 3.11, uv 0.13.1 y ejecuta `uv sync --locked --no-dev`. Para el laboratorio, Python 3.11+ basta para la auditoría, Treasury, MiniBench y los tests. Los estudios históricos requieren además NumPy. Ejecuta `python -m unittest discover -s research -p 'test_*.py'`. Los tres comandos de ejecución individual están en el workflow. Para recuperar un día ausente, despacha el control con la interfaz GitHub Actions sobre main; mantiene la primera emisión de cada pronóstico y no reconstruye semanas pasadas.
6. Para decidir un ascenso, compara pérdidas y cobertura sobre la misma población y fechas, revisa horizonte, disponibilidad, precisión y coste. Comprueba el resultado en una prueba prospectiva separada y usa el área de test antes de cualquier despliegue. El circuito no tiene una acción que promueva modelos a producción automáticamente.

## Panel independiente de Treasury y crédito de API

El [panel preregistrado](promo/panel.json) tiene cuatro resultados binarios y dos fechas de diciembre de 2026. Los resultados de [Gemini y Codex](promo/sealed) y las probabilidades de referencia se sellaron antes de conocer esas observaciones. GitHub compara después las probabilidades con el XML oficial. El cálculo consume cero créditos de modelos. Revisa la [puntuación vigente](https://github.com/xmjunior/mmegalab-futureeval-bot/blob/research/champion-observations/records/promo-score.json).

Para restaurar este panel conserva también la rama `research/openai-promo-ledger-v2` con su historial. Almacena las reservas de cada llamada y los intentos finalizados. El workflow de verificación para Gemma hace un único intento con el texto común y registra una respuesta fallida como tal. El [protocolo del presupuesto](promo/BUDGET.md) mantiene el permiso de OpenAI separado del bot de competición. Al caducar la promoción, todos los motores gratuitos continúan con sus credenciales originales. La [comparación de modelos sobre pronósticos archivados](forecastbench/openai/SUMMARY.md) recoge rendimiento, fechas y límites de la evidencia.
